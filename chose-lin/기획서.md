# 혼돈의 궤적 (Chaos Trajectory) — 게임 개발 기획서

작성일: 2026-07-14
버전: 1.0

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 게임 이름 | 혼돈의 궤적 |
| 장르 | 루트 파밍(Loot Farming) 생존 액션 |
| 플랫폼 | 웹 브라우저 (PC / 모바일 겸용) |
| 조작 방식 | 키보드(방향키·F·A·S) / 터치(D패드·액션 버튼) |
| 플레이 시간 | 1판당 최대 10분 |
| 저장 방식 | 브라우저 로컬 저장(localStorage) |
| 개발 파일 구성 | `index.html`, `styles.css`, `script.js` |

### 1.1 한줄 소개
> **"제한된 시간 안에 위험한 필드에서 아이템을 파밍하고 살아 돌아오라."**

### 1.2 핵심 매력
- **긴장감 있는 시간 압박** — 10분이라는 명확한 제한 시간
- **결정의 무게** — 더 많이 파밍할 것인가, 안전하게 나갈 것인가
- **완전 상실의 리스크** — 사망 시 이번 판 획득분 전부와 장착 무기까지 상실
- **모바일 친화적** — 한 손으로도 조작 가능한 UI 구성

---

## 2. 게임 목표

### 2.1 플레이어의 목표
1. **단기(1판 기준):** 필드에서 아이템을 최대한 파밍하고 탈출구를 통해 살아 나오기
2. **장기:** 인벤토리에 강력한 무기와 자원을 축적하여 더 위험한 필드에도 도전 가능해지기

### 2.2 실패 조건
- 필드 내에서 체력이 0이 됨 (몹에 의한 사망)
- 필드에서 10분이 경과함 (시간 초과)

### 2.3 성공 조건
- 필드 내 3개 탈출구 중 하나에 도달하여 F키(획득)로 탈출 활성화

## 3. 게임플레이

### 3.1 핵심 게임 루프

```
[메인 메뉴]
    │
    ├─ 필드 선택 (5종 중 택1)
    │       │
    │       ▼
    │  [필드 진입 — 최대 10분]
    │       │
    │       ├─ 이동, 아이템 획득, 몹 회피/공격, 회복
    │       │
    │       └─ 종료 조건 발생 ─┐
    │                          │
    │  ┌───────────────────────┤
    │  │ 탈출 성공 → 아이템 인벤토리로 이전
    │  │ 사망     → 이번 판 획득분 + 장착 무기 상실
    │  │ 시간초과 → 이번 판 획득분 + 장착 무기 상실
    │  ▼
    │ [종료 화면] — 결과 표시
    │       │
    ▼       ▼
[메인 메뉴로 복귀]
    │
    └─ 인벤토리 확인 / 무기 장착
```

### 3.2 조작

| 조작 | 키보드 | 터치 |
|---|---|---|
| 이동 | 방향키 ↑↓←→ | 화면 좌측 D패드 |
| 아이템 획득 / 탈출 활성화 | F | 획득 버튼 |
| 무기 휘두르기 | A | 공격 버튼 |
| 회복약 사용 | S | HUD 상단 포션 아이콘 탭 |

> 무기 휘두르기(A)와 회복약 사용(S)은 필드에서만 동작합니다.

### 3.3 화면 구성

#### 3.3.1 메인 메뉴
- 게임 타이틀 "혼돈의 궤적"
- 부제 "루트 파밍 생존 게임"
- 버튼: **필드로 이동** / **인벤토리**

#### 3.3.2 필드 선택
- 2×3 그리드에 필드 이모지 + 이름 (숲🌲, 황야🏜️, 초원🌾, 도심🏙️, 지하🕳️)
- 각 필드는 배경색/바닥 격자 색상으로 시각적 구분
- 하단 **뒤로** 버튼

#### 3.3.3 인벤토리
- **장착 중 슬롯** — 현재 장착한 무기 표시(없으면 "없음"), 해제 버튼
- **무기** 섹션 — 보유한 무기 목록, 각 무기 옆 "장착" 버튼 또는 "장착 중" 배지
- **아이템** 섹션 — 회복약 개수, 재료 개수
- 하단 **뒤로** 버튼

#### 3.3.4 필드(게임 화면)
- 상단 HUD: 필드 이름 뱃지 · 타이머(MM:SS) · 체력 바 · 장착 무기 이름 · 포션(S)/재료 카운트
- 중앙: 캔버스 게임 화면 (4:3 비율, 최대 700px 폭)
- 하단: D패드(4방향) + 액션 버튼(획득 F, 공격 A)

#### 3.3.5 종료 화면
- 결과 제목 ("탈출 성공!", "쓰러졌습니다...", "시간 초과")
- 결과 메시지
- 획득 아이템 목록(탈출 성공) / "획득한 아이템이 없습니다" (실패)
- **메인으로** 버튼

## 4. 게임 규칙

### 4.1 플레이어

| 스탯 | 값 |
|---|---|
| 최대 체력 | 100 |
| 이동 속도 | 180 px/초 |

- 필드 진입 시 체력 100 만땅으로 시작
- 인벤토리에서 무기를 장착한 상태로 진입 시 그 무기를 들고 시작

### 4.2 몹

두 종류의 몹이 필드에 배회한다.

| 몹 종류 | 이모지 | 특징 |
|---|---|---|
| 오브스터 | 🦂 | 지상형 위협 |
| 하이브 | 🐝 | 지상형 위협 |

*(두 몹은 현재 스탯상 동일하며, 시각적 차별화만 존재)*

| 스탯 | 값 |
|---|---|
| 배회 속도 | 50 px/초 |
| 추적 속도 | 100 px/초 (플레이어보다 느림) |
| 시야 감지 반경 | 150 px |
| 추적 유지 시간 | 시야 이탈 후 3초 |
| 충돌 판정 반경 | 22 px |
| 연속 피격 쿨다운 | 900ms |
| 기절 지속 | 500ms (플레이어 공격 시) |

#### 4.2.1 몹 AI 상태 다이어그램

```
   [배회]
     │  플레이어가 시야 반경 진입
     ▼
   [추적] ─── 시야 벗어난 지 3초 경과 ─→ [배회]
     │                                       ▲
     ▼                                       │
   플레이어 근접 시 접촉 데미지               │
     │                                       │
     ▼                                       │
   플레이어의 공격에 맞으면 [기절 0.5초] ────┘
```

- **배회**: 무작위 지점을 향해 이동, 지점 도달 시 새 지점 지정
- **추적**: 플레이어 위치로 직선 이동
- **기절**: 이동/추적 상태 무시, 정지

### 4.3 전투

- **몹의 데미지**: 접촉 시 플레이어 체력의 **20% (=20)** 감소
- **연속 피격 방지**: 같은 몹에게 0.9초 내 연속 피격당하지 않음
- **플레이어 공격**: 무기를 착용한 상태에서 A키 → 공격 반경(60px) 내 모든 몹이 0.5초 기절
- **무기 없이 공격 불가**

### 4.4 아이템

세 종류의 아이템이 필드에 스폰된다.

| 아이템 | 이모지 | 획득 시 효과 |
|---|---|---|
| 무기 | 🗡️ | 즉시 장착 (이전 무기 대체·소멸) |
| 회복약 | 🧪 | 러닝 인벤토리에 저장, S키로 사용 시 체력 5% 회복 |
| 재료 | 💎 | 러닝 인벤토리에 저장 |

#### 4.4.1 무기 이름 풀
녹슨 단검, 뼈 몽둥이, 부러진 파이프, 강철 도끼, 이빨 창

#### 4.4.2 재료 이름 풀
가죽 조각, 금속 파편, 이상한 결정, 나무 조각, 녹슨 나사

#### 4.4.3 스폰 규칙
- 필드 진입 시 아이템 10개 무작위 스폰
- 스폰 확률 가중치: 무기(3) / 회복약(4) / 재료(3)
- 획득 반경: 40px 이내에서 F키 → 가장 가까운 하나 획득

### 4.5 필드

| 필드 이름 | 이모지 | 배경 톤 |
|---|---|---|
| 숲 | 🌲 | 어두운 녹색 |
| 황야 | 🏜️ | 갈색·황토 |
| 초원 | 🌾 | 어두운 녹황 |
| 도심 | 🏙️ | 회색·청색 |
| 지하 | 🕳️ | 거의 검정 |

- 필드 크기: 800×600 px (고정)
- 필드 진입 시 몹 6마리 스폰 (오브스터 3, 하이브 3)
- **탈출구 3개**: 좌상단 · 우측 중앙 · 좌하단에 고정 배치, 반경 34px

### 4.6 타이머

- 필드 진입 시 10:00으로 시작
- 매초 감소, 상단에 MM:SS로 표시
- 0:00 도달 시 **시간 초과** 종료

| 종료 조건 | 이번 판 획득분 | 장착했던 무기 | 인벤토리 잔여물 |
|---|---|---|---|
| 탈출 성공 (F키 in 탈출구) | 인벤토리로 이전 | 인벤토리로 복귀 | 유지 |

- 탈출 성공 시에는 결과 화면에 획득 아이템 목록 표시

## 6. 인벤토리 시스템

### 6.1 영구 인벤토리 (`state.inventory`)
```
{
  weapons: [무기 이름들...],
  potion: 회복약 개수,
  material: 재료 개수,
  equippedWeapon: 장착 지정 무기 이름 또는 null
}
```

- `localStorage`에 JSON 형태로 저장 (키: `chaos-trajectory-inventory-v1`)
- 브라우저를 새로 열어도 유지되며, 다른 기기에는 동기화되지 않음

### 6.2 러닝 인벤토리 (`field.runInventory`)
필드에서 임시로 획득한 아이템 저장소. 필드 종료 시:
- 탈출 성공 → 영구 인벤토리로 병합
- 사망/타임아웃 → 폐기

### 6.3 장착 시스템
- 인벤토리에서 무기 옆 **장착** 버튼 클릭 → `equippedWeapon` 지정
- 필드 진입 시: `equippedWeapon`을 인벤토리에서 꺼내 필드로 이동, `player.weapon`에 세팅
- 탈출 성공 시: 처음 들고 나간 무기 + 필드에서 획득한 모든 무기가 인벤토리로 복귀
- 사망/타임아웃 시: 들고 나간 무기 소멸

## 7. 기술 사양

### 7.1 파일 구조
```
chose-lin/
├── index.html    — 화면 구조, HUD, 컨트롤 배치
├── styles.css    — 반응형 스타일, 다크 테마, 모바일 대응
└── script.js     — 게임 로직, 상태 관리, 렌더링
```

### 7.2 사용 기술
- **HTML5 Canvas 2D** — 필드 렌더링
- **CSS3 flex/grid** — 반응형 UI 레이아웃
- **Vanilla JavaScript** — 프레임워크 없음
- **localStorage** — 저장

### 7.3 게임 루프
- `requestAnimationFrame` 기반
- 델타 타임(dt) 최대 0.05초로 클램프하여 백그라운드 복귀 시 급진행 방지

### 7.4 반응형 대응
- 캔버스는 최대 700px 폭, 4:3 비율 유지
- 380px 이하 화면에서는 D패드·액션 버튼 크기 축소
- `meta viewport`로 확대 축소 방지 (모바일 조작 편의성)

## 8. UI/UX 원칙

1. **모바일 우선** — 화면 하단에 D패드·액션 버튼을 항상 노출
2. **텍스트+그래픽 병행** — 체력바와 함께 숫자(예: "70 / 100")도 표시
3. **상태 즉시 피드백** — 몹 추적 상태(빨간 점), 기절(★), 공격 판정(청색 링), 탈출구 근접(초록 "F: 탈출하기") 등
4. **어두운 톤 + 강한 강조색** — 배경은 다크, 액션 요소는 보라·핑크로 강조
5. **일관된 뒤로가기** — 모든 서브 화면에 뒤로 버튼 배치
