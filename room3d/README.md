# 고른 공간

## 주소
https://yj78615-blip.github.io/AIFFEL_Quest/room3d/

## 어디를 골랐나

* 개인 작업 데스크
* 개인 작업 데스크까지는 개인정보가 많이 존재 하지않기 때문

## 어떻게 찍었나
- 길이 22.5초, 720p, 뽑은 장수 24장
- 카메라가 퍼진 정도 0.47 (0.1이 기준선)
- 나온 점 326만 개 (원본) → 100만 개 (배포본, decimate로 줄임)

## 형식별로 잰 값 (배포본 100만 알갱이 기준)
| 형식 | 파일 크기 | 알갱이 개수 | 알갱이당 바이트 |
|---|---|---|---|
| .ply | 64.8 MB | 1,000,000 | 68.0 |
| .compressed.ply | 15.5 MB | 1,000,000 | 16.3 |
| .sog | 8.9 MB | 1,000,000 | 9.3 |
| .spz | 10.7 MB | 1,000,000 | 11.2 |

원본 326만 알갱이 .sog는 15.7MB였다. 알갱이당 바이트가 5.0에서 9.3으로 오른 것은 .sog의 헤더·메타데이터 오버헤드가 알갱이가 적을수록 상대적으로 커지기 때문.

## 폰에서 첫 화면까지
- 폰 미측정, 데스크탑 약 3.5초 (원본 15.7MB 기준)
- 배포본 8.9MB로 줄여 파일 다운로드가 약 43% 짧아짐

## 안 나온 자리
- 자세히 찍히지 않은 외곽 부근에 검은 얼룩이 남았다. 그 자리를 지나며 좌우로 조금 더 움직여 찍었더라면 시차가 생겨 채워졌을 것.

## 걸린 시간
| 걸음 | 첫 실행 | 재실행(캐시) |
|---|---|---|
| 모델 로드 | 471s | 40s |
| 복원 | 144s | 164s |
| sog 변환 | 11s | 13s |
| 총합 | 약 626s | 약 217s |

첫 실행에서 걸린 시간의 대부분은 HF 가중치 4.9GB와 dinov2 zipball 다운로드. 이후엔 캐시에서 로드해 약 3배 빠름.
